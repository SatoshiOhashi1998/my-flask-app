API Tool

Markdown

Daily Noteを作成

GET /api/markdown/create_dailynote

指定した日付からDaily Noteを作成します。 日付を空欄にするとAPI側のデフォルト値が使用されます。

英語語彙を出力

GET /api/markdown/export_english

語彙を出力

GET /api/markdown/export_vocablary

Weekly Noteを作成

GET /api/markdown/create_weekly_note

指定した日付を含む週のWeekly Noteを作成します。

次週のWeekly Noteを作成

GET /api/markdown/create_next_weekly_note

Weather

今日の天気を取得

GET /api/weather/get/today

明日の天気を取得

GET /api/weather/get/tomorrow

Calendar

今日のタスクを同期

GET /api/calendar/sync-tasks/today

明日のタスクを同期

GET /api/calendar/sync-tasks/tomorrow

指定日のタスクを同期

GET /api/calendar/sync-tasks/date

15時までのタスクを同期

GET /api/calendar/sync-tasks/before-15

18時までのタスクを同期

GET /api/calendar/sync-tasks/before-18

18時以降のタスクを同期

GET /api/calendar/sync-tasks/after-18

Clipboard

コードをコピー

POST /api/clipboard/copy-code

指定したディレクトリやファイルのコードをクリップボードへコピーします。

ファイル構成をコピー

POST /api/clipboard/copy-file-tree

指定したディレクトリ以下のファイル構成をクリップボードへコピーします。

Media

動画のOriginal Nameを変更

PATCH /api/videos/<video_id>/original-name

音楽のOriginal Nameを変更

PATCH /api/musics/<music_id>/original-name

Maintenance

Media情報をリセット

GET /api/reset/media

Mediaのメタデータを更新し、存在しないメディアのDBエントリを削除します。
